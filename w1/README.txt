Sistem Manajemen Rental Mobil Land Rover yang dikembangkan ini 
merupakan aplikasi web dua halaman yang dirancang untuk menampilkan 
armada kendaraan khusus Land Rover serta memfasilitasi proses pemesanan.
 Dibangun dengan memanfaatkan Bootstrap 5 sebagai framework CSS utama, 
proyek ini mengedepankan tata letak responsif yang optimal di berbagai perangkat. 
Penggunaan ikon Bootstrap memperkaya antarmuka dengan elemen visual yang intuitif, 
sementara CSS eksternal memungkinkan kustomisasi gaya secara terpisah dan terstruktur.
Kode JavaScript sederhana ditambahkan untuk memvalidasi input pengguna, memastikan data
 yang dimasukkan memenuhi kriteria dasar sebelum diproses.

Halaman utama (index.html) menyajikan hero section dengan gambar latar penuh yang dilapisi 
overlay gelap agar teks terbaca jelas, diikuti section produk yang menampilkan enam kartu
 mobil (Range Rover 2005, 2007, Sport 2005, Discovery 3, Discovery 4, dan Defender 2007). 
Setiap kartu dilengkapi gambar placeholder, deskripsi singkat, harga sewa, dan tombol aksi
 menuju halaman booking. Halaman booking (booking.html) memuat formulir pemesanan dengan empat 
field wajib (nama, pilih mobil, tanggal sewa, lama sewa) yang divalidasi menggunakan atribut HTML5
 required dan fungsi JavaScript tambahan untuk memastikan lama sewa minimal satu hari. 
Navigasi antar halaman dipermudah melalui navbar yang konsisten di kedua halaman.
